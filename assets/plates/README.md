# Part illustration plates

The book reserves an optional four-page coated-paper unit for each Part. No
plate unit is enabled until all four external illustrations for that Part are
ready.

## File contract

Place trim-sized PDFs at:

```text
assets/plates/part01/page-01.pdf ... page-04.pdf
assets/plates/part02/page-01.pdf ... page-04.pdf
assets/plates/part03/page-01.pdf ... page-04.pdf
```

Print masters should be supplied at 131 x 182 mm: ISO B6 trim (125 x 176 mm)
plus 3 mm bleed on every edge. Keep important content at least 8 mm inside the
trim edge. Prefer vector PDF or 300 ppi CMYK raster artwork. Do not add crop
marks or folios to the artwork itself.
